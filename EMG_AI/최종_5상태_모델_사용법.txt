퍼플팀 EMG 최종 5상태 모델

판정 상태
- 휴식
- 검지 움직임
- 중지 움직임
- 약지 움직임
- 주먹 쥐기

현재 모델
- 학습 데이터: 2026-09-02 품질검사 통과 413회
- RF 시험 기록 정확도: 78.0%, macro F1 0.779
- 1D CNN 시험 기록 정확도: 90.2%, macro F1 0.915
- 권장: 1D CNN

실시간 판정
1. Arduino IDE 시리얼 모니터와 RAW 측정기를 닫는다.
2. EMG_측정_프로그램\퍼플팀_EMG_RF_CNN_5상태_판별기_v5.exe를 실행한다.
3. RF 또는 1D CNN 하나만 선택하고 "선택 모델 켜기"를 누른다.
4. COM 포트를 연결한 뒤 3초 동안 손과 팔에 힘을 완전히 뺀다.
5. 전극을 다시 붙이거나 휴식 신호가 달라지면 휴식 기준 재설정을 누른다.

재학습
- 최신 날짜 폴더의 정상 수동/무작위 데이터를 자동 사용한다.
- EMG_AI\최종_RF_CNN_다시_학습.bat을 실행하면 사전검사 후 두 모델을 모두 새로 학습한다.
- 학습 결과는 EMG_AI\outputs_final_5class에 저장된다.

한계
- 현재 시험은 같은 날짜의 뒤쪽 회차를 따로 떼어 평가한 것이다.
- 전극을 완전히 다시 붙인 다른 세션에서의 성능은 아직 확정할 수 없다.
